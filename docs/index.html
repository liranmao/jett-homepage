关于我

来自韩国的决斗特工，战斗风格灵活、迅捷，擅长利用机动能力采取冒险行动，并在交战中出其不意地攻击对手。

自我介绍（趣味改写）：擅长把“这里进不去”变成“我已经进去了”。移动办公经验丰富，办公地点包括半空。

本页为捷风官方设定的简历形式改写，用于建站演示。身份与技能依据 Riot 官方资料；岗位描述和技能案例为演示用改写，不是官方履历、角色台词或真实战绩。

技能

  • 瞬云 Cloudburst｜投出可短暂遮挡视线的云雾；按住技能键，可用准星引导其轨迹。
  • 凌空 Updraft｜迅速腾空跃起。简历版描述：具备垂直方向的岗位拓展能力。
  • 逐风 Tailwind｜先准备风力，再朝移动方向突进；静止时向前突进。
  • 飓刃 Blade Storm｜装备高精度飞刀，可单发或一次掷出余下飞刀；单发击杀可补充飞刀，齐射击杀不补充。
  • 飘移 Drift｜下落时按住跳跃键，可在空中滑翔。简历版描述：落地之前，仍有操作空间。
  • 岗位匹配（趣味改写）｜适合需要机动性与主动交战的决斗位。本人负责冲得快，团队配合负责让这次突进有意义。
  • 技能边界｜瞬云是短暂遮挡，不等于完整控场方案；请不要看到我有烟，就把所有封烟任务交给我。
